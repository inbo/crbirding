# crbirding: Prepare CR-Birding Data For Publication

Prepare colour-ringing data from 'CR-Birding'
(<https://submit.cr-birding.org/>) for publication in a research
repository. With 'crbirding' you can transform CR-Birding data to Darwin
Core for publication to the Global Biodiversity Information Facility
('GBIF') and the Ocean Biodiversity Information System ('OBIS').
